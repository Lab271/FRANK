FRANK Anonymised threat-sighting sharing
public

Paste a submission (Phase 2 JSON format, one or an array). The preview runs in your browser, with the same code the server runs (WebAssembly): these rows are everything that is shared. Organisation identities are never stored.

Partners download the sightings Parquet files and query them here, in the browser, on db-core's column engine compiled to WebAssembly. Nothing is sent back. Counts, sums, minimums and maximums merge across files; other results are shown per file.
