Authentication Instructions

Service accounts authenticate using standard Cognito JWT tokens. Use the following example to authenticate:

AWS Cognito InitiateAuth

curl -X POST https://cognito-idp.{region}.amazonaws.com/ \
  -H "Content-Type: application/x-amz-json-1.1" \
  -H "X-Amz-Target: AWSCognitoIdentityProviderService.InitiateAuth" \
  -d '{
    "AuthFlow": "USER_PASSWORD_AUTH",
    "ClientId": "{your_client_id}",
    "AuthParameters": {
      "USERNAME": "{{ service_username }}",
      "PASSWORD": "{{ generated_password }}"
    }
  }'

FRANK Management API Login

curl -X POST http://localhost:8001/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "{{ service_username }}",
    "password": "{{ generated_password }}"
  }'

Using the JWT Token

# Save the access token from the login response
ACCESS_TOKEN="eyJraWQiOiJ..."

# Make authenticated API requests
curl -X GET http://localhost:8001/v1/organisations \
  -H "Authorization: Bearer ${ACCESS_TOKEN}"

Token Details

  • Algorithm: RS256 (RSA Signature with SHA-256)
  • Lifetime: 1 hour (3600 seconds)
  • Validation: Stateless via Cognito JWKS endpoint
  • Refresh: Use refresh token to get new access tokens
